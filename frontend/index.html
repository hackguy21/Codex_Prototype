기타

Project Hormuz의 현재 구조와 구현 경계를 확인합니다.

코드 구조

  • frontend/: 프로젝트 네비게이션, 모니터링 패널, 결과 표시 UI
  • backend/server.py: 정적 파일 제공과 JSON API 라우팅
  • backend/projects/meta_project/: 메타 프로젝트 설정, 선택 프로젝트 실행, 텔레그램 전송 흐름
  • backend/projects/traffic_monitor/: 구역 설정과 FlightRadar24/MarineTraffic 스캐폴드 응답
  • data/: 메타 설정과 구역 설정 JSON 저장소

현재 기능

  • META PROJECT: Daily Monitor 프로젝트의 수집 및 요약, 텔레그램 전송
  • FlightRadar24: 호르무즈 구역 항공 모니터링 스캐폴드
  • MarineTraffic: 호르무즈 구역 해상 모니터링 스캐폴드
  • 보류된 구현: 실제 캡처, 이미지 저장, 변화 감지, 텔레그램 이미지 전송
