Project Prototype

바이브코딩에 사용되는 CSS/UI와 아키텍처의 프로토타입을 제공합니다

전체 프로젝트 요약

META PROJECT와 NORMAL PROJECT를 구분해 현재 프로젝트 구성을 요약합니다.

프로젝트 목록

코드구조 및 현재규칙

CSS/UI 패턴과 로컬 아키텍처 프로토타입의 구성 요소를 확인합니다.

코드 구조

  • frontend/: 사이드바, 패널, 리스트, 결과 영역 등 바이브코딩용 UI 패턴
  • backend/server.py: 정적 파일 제공과 JSON API 라우팅을 담당하는 표준 라이브러리 서버
  • backend/projects/meta_project/: 메타프로젝트 카탈로그, 카테고리 구분, 설정 정규화
  • backend/projects/normal_project/: 일반 기능 프로젝트가 추가되는 기본 위치
  • backend/projects/normal_project/example_1/: NORMAL PROJECT에 등록된 첫 예시 프로젝트
  • data/meta_project/: 화면 구성과 프로토타입 설정을 보관하는 JSON 저장소

현재 규칙

  • META PROJECT: 전체 요약, 구조 설명, 설정 관리처럼 워크스페이스를 관리하는 화면 그룹
  • NORMAL PROJECT: 사용자가 일반적으로 추가하는 기능 프로젝트가 들어가는 화면 그룹
  • category: 카탈로그의 `meta_project`와 `normal_project` 값으로 두 그룹을 구분
  • normal_project: 바이브코딩이나 수작업으로 구현한 일반 기능 코드를 우선 담는 backend 폴더
  • example_1: NORMAL PROJECT와 `backend/projects/normal_project/example_1/`의 예시 프로젝트

수집정보 외부 전송

일반 프로젝트에서 수집한 정보를 외부 API, 웹훅, 파일 저장소 등으로 전송하기 전 내용을 정리하는 메타 프로젝트입니다.

프로젝트 설명

  • 목적: 각 NORMAL PROJECT에서 수집한 결과물을 외부로 보낼 수 있도록 정리합니다.
  • 입력: 전송 대상, 전송 방식, 수집 정보, 설명 메모를 입력합니다.
  • 출력: 전송 전에 확인할 요약 내용이나 결과 메시지를 표시합니다.
  • 현재 상태: 프론트엔드 화면 슬롯만 만든 상태이며, 실제 전송 로직은 아직 연결하지 않습니다.

전송 정보 입력

아직 실제 전송 기능은 연결되어 있지 않습니다.

example_1

normal_project 아래에 추가되는 일반 프로젝트 예시입니다.

위치

  • backend/projects/normal_project/example_1/: 이 프로젝트의 백엔드 코드 위치
  • NORMAL PROJECT: 프론트 네비게이션에서 일반 프로젝트를 모아두는 그룹
  • 확장 방식: 새 일반 프로젝트는 `normal_project` 아래에 폴더를 추가하고 이 네비게이션 그룹에 연결합니다.

상태

예시 프로젝트 슬롯입니다. 아직 실행 로직은 없습니다.
