기타

CSS/UI 패턴과 로컬 아키텍처 프로토타입의 구성 요소를 확인합니다.

코드 구조

  • frontend/: 사이드바, 패널, 리스트, 결과 영역 등 바이브코딩용 UI 패턴
  • frontend/styles.css: 재사용 가능한 레이아웃, 카드, 버튼, 상태 표시 스타일
  • frontend/app.js: 화면 상태, API 호출, 렌더링, 기본 상호작용 핸들러
  • backend/server.py: 정적 파일 제공과 JSON API 라우팅을 담당하는 표준 라이브러리 서버
  • backend/projects/meta_project/: 프로젝트 카탈로그, 설정 정규화, 프로토타입 실행 흐름
  • data/: 화면 구성과 프로토타입 설정을 보관하는 JSON 저장소

현재 기능

  • Project Prototype: 바이브코딩에 사용할 CSS/UI와 아키텍처 샘플 제공
  • 메타프로젝트: 프로젝트 구조, 설정, 실행 흐름을 한 화면에서 확인하는 컨트롤 패널
  • UI 스캐폴드: 실제 도메인 로직을 붙이기 전 사용할 기본 화면과 API 연결 구조
  • 확장 지점: 새 프로젝트, 데이터 저장소, 실행 어댑터를 추가할 수 있는 폴더 구조
